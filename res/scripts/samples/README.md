# HypScript Language Samples

This directory contains comprehensive examples of the HypScript language features used in the Hyperion Engine. Each file demonstrates specific language constructs and best practices.

## Sample Files

### 01_basic_variables.hyp
- Variable declarations with type inference and explicit typing
- Basic data types: int32, float, string, bool
- Arrays and array manipulation
- Reference variables

### 02_functions.hyp
- Function definitions with parameters and return types
- Default parameters
- Lambda functions and function expressions
- Higher-order functions
- Function composition

### 03_classes_inheritance.hyp
- Class definitions and constructors
- Inheritance with base classes
- Method overriding and super calls
- Object instantiation and method calls

### 04_enums.hyp
- Enumeration definitions with explicit types
- Enum values and type casting
- Using enums in classes and functions
- Comparison operations with enums

### 05_control_flow.hyp
- Conditional statements (if/else)
- Loop constructs (for, while)
- Nested loops and complex control flow
- Loop control with break/continue

### 06_operator_overloading.hyp
- Arithmetic operator overloading (+, -, *, /)
- Comparison operators (==, !=)
- Array access operators ([], []=)
- Unary operators (-)
- Custom mathematical operations

### 07_static_members.hyp
- Static variables and methods
- Class-level functionality
- Static constructors and initialization
- Utility classes with static methods

### 08_arrays_data_structures.hyp
- Advanced array operations (filter, map, reduce)
- Higher-order functions with arrays
- Multi-dimensional arrays
- Custom data structure implementations

### 09_variadic_functions.hyp
- Functions with variable arguments
- Variadic constructors and methods
- Argument spreading and collection
- Real-world usage patterns

### 10_lambdas_closures.hyp
- Lambda function syntax and usage
- Closures and variable capture
- Function factories and configuration
- Event systems using lambdas

### 11_type_casting_any.hyp
- Type casting between primitives
- Using the 'any' type for dynamic typing
- Generic containers and type safety
- Runtime type checking and conversion

### 12_references_memory.hyp
- Reference variables and parameters
- Object references and shared state
- Linked data structures
- Memory management patterns

### 13_external_interface.hyp
- External class declarations
- Interfacing with engine types (Vec3f, Entity, Scene)
- Wrapper functions for engine integration
- Best practices for external bindings

### 14_complex_game_system.hyp
- Complete game system example
- Event-driven architecture
- State management
- Object-oriented game entity design
- Combining multiple language features

## Language Features Demonstrated

- **Type System**: Static typing with inference, primitive types, custom types
- **Object-Oriented**: Classes, inheritance, polymorphism, encapsulation
- **Functional**: Lambda functions, closures, higher-order functions
- **Memory**: Reference semantics, object lifecycle management
- **Interop**: External declarations for engine integration
- **Advanced**: Operator overloading, variadic functions, generic programming

## Usage

These samples can be used as:
- Learning materials for HypScript syntax and features
- Reference implementations for common patterns
- Starting points for game scripting
- Test cases for language feature verification

Each file is self-contained and can be compiled and executed independently to demonstrate the specific features it covers.
